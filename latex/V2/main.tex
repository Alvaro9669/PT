\subsection{Planteamiento del problema}

Para este proyecto el principal problema sera la creación de una Base de datos robusta y que un bot de discord pueda tener acceso a estos datos para poder desarrollar su función de recordar o informar al usuario de sus pagos ya sea de compra realizadas o de suscripciones por vencerse.\\

La base de datos o el bot deberán tener un sistema de alertas o trigers(disparadores) para saber cuando hay una nueva entrada en la base de datos y que a su vez el bot de Discord sepa cuando tiene que informar al usuario, estas alertas serán: \\
1.- Al acercarse la fecha de un próximo pago de una suscripción mensual.\\
2.-Al ingresar una nueva entrada en la Base de Datos por una compra hecha por el usuario.\\

Otro reto dentro del proyecto sera la creación del bot de discord ya que este debe generar los informes tanto para el usuario como para el administrador y darles un canal privado a ambos para que puedan continuar con los detalles de la compra si es que se requiere, es por eso que la base de datos debe ser lo suficientemente robusta y bien planificada para tener la capacidad de gestionar de forma eficiente los datos que ocupara el bot.

\section{Objetivos}
\subsection{Objetivo general}
Desarrollar una tienda en línea integrada con un bot de Discord para optimizar la experiencia de compra de los usuarios y mejorar la gestión de suscripciones y notificaciones, tanto para los clientes como para los administradores de la tienda. Esta integración buscará resolver las limitaciones actuales del comercio electrónico en términos de comunicación efectiva y personalizada, permitiendo a los usuarios recibir actualizaciones en tiempo real sobre sus compras y suscripciones, mientras que los propietarios del servidor obtienen información detallada sobre las transacciones. El proyecto tiene como finalidad ofrecer una solución tecnológica innovadora, basada en la automatización de procesos y la comunicación directa a través de una plataforma de mensajería muy utilizada, como lo es Discord.\\

\subsection{Objetivos específicos}
Para este proyecto se tienen los siguientes objetivos específicos \\
1.- Desarrollar una base de datos centralizada que almacene y gestione la información de las compras y suscripciones.\\

2.- Diseñar e integrar un bot de Discord que actúe como asistente personal de los usuarios.\\

3.- Desarrollar un sistema de notificaciones automatizadas para el dueño del servidor de Discord.\\

4.-Desarrollar una lógica capaz de identificar cuando el bot debe notificar al usuario de su compra o suscripciones (deste BD o logica en el bot de discord).\\

5.- Facilitar la gestión de compras y suscripciones para los usuarios así como la gestión de los artículos de la tienda desde el lado de el administrador.\\

Las tecnologias para este proyecto seran API PayPal, API Discord, 
 MYSQL, PHP, Node.js, React. Se explicaran cada una de las tecnologías para definir que funcionalidad van a desempeñar en el proyecto propuesto.
\subsection{PayPal}

\begin{wrapfigure}{r}{0.30\textwidth}
    \includegraphics[width=0.40\textwidth]{proyecto terminal/Logos/pplogo.png}
\end{wrapfigure}


PayPal es una de las plataformas más utilizadas para el comercio electrónico gracias a que nos permite realizar pagos de forma rápida y fácil. Para este proyecto se ha decidido usar PayPal ya que los usuarios a los que está dirigida la plataforma tienen conocimientos y cuentan con este método de pago. Además, PayPal permite pagos desde otros países de forma sencilla, lo que le otorga ventaja sobre otras plataformas similares como Mercado Pago.\\

La integración de PayPal en esta plataforma de ventas permite un manejo flexible y seguro de las transacciones, asegurando que los pagos de los usuarios se procesen correctamente y sin complicaciones.

\subsection{PHP}

\begin{wrapfigure}{l}{0.20\textwidth}
    \includegraphics[width=0.20\textwidth]{proyecto terminal/Logos/phplogo.png}
\end{wrapfigure}
PHP se utiliza para generar páginas web dinámicas que cambian en función de la interacción del usuario o de datos en una base de datos. Un ejemplo seria, al iniciar sesión en un sitio web o navegar por una tienda online, PHP es responsable de mostrar contenido específico para el perfil como productos personalizados etc.\\

Es por esta razón que para este proyecto se utilizara php para hacer la lógica de el lado del servidor y poder darle las instrucciones de gestión de la base de datos, para mostrar, agregar, modificar.\\

PHP también nos brinda buenas opciones de seguridad como Prepared Statements (Consultas Preparadas) que protege contra las inyecciones SQL, esta es otra de las razones por las que se ha elegido esta tecnología para el proyecto.

\subsection{React}

\begin{wrapfigure}r{0.25\textwidth}
    \includegraphics[width=0.25\textwidth]{proyecto terminal/Logos/reactlogo.png}
\end{wrapfigure}
React es una biblioteca de JavaScript que es usada para construir interfaces de usuario (UI) interactivas y dinámicas.Su principal objetivo es facilitar la creación de interfaces de usuario a través de componentes reutilizables y actualizaciones eficientes del DOM (Document Object Model).\\

Esta biblioteca se basa en componentes, lo que permite dividir una interfaz en piezas pequeñas y manejables que se pueden reutilizar en diferentes partes de la aplicación, mejorando así la mantenibilidad del código.\\

Por su facilidad para crear interfaces dinámicas y que es fácil de mantener a largo plazo es por lo que se eligió esta tecnología sobre otras similares.\\

\subsection{MySQL}

\begin{wrapfigure}{l}{0.20\textwidth}
    \includegraphics[width=0.20\textwidth]{proyecto terminal/Logos/mysqllogo.png}
\end{wrapfigure}
MySQL es un sistema de gestión de bases de datos relacional que utiliza el lenguaje SQL para administrar y manipular datos. Es muy utilizado para almacenar, organizar y gestionar grandes cantidades de información en aplicaciones de software.\\

A través de SQL, MySQL permite realizar consultas complejas sobre los datos almacenados. Esto incluye operaciones como selección, eliminación, inserción, actualización de datos etc.\\

En este proyecto es muy importante tener una base de datos muy solida y para poder gestionarla de forma adecuada se selecciono MySQL gracias a su gran capacidad de manejo de datos.
